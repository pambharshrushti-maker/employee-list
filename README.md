# EMPLOYEE MANAGEMENT SYSTEM

## Project Title

Employee Management System using React.js and JSON Server

---

## 1. Introduction

Employee Management System is a web-based application developed using React.js and JSON Server.

The main purpose of this project is to display and manage employee information in an organized and user-friendly way.

The application displays employee details such as Employee ID, Name, Email, Age, Department, Salary, and Location.

---

## 2. Objectives

The main objectives of this project are:

- To create an employee management interface.
- To display employee information in a table.
- To fetch employee data using JSON Server.
- To implement employee search functionality.
- To implement pagination.
- To create a responsive and user-friendly interface.
- To understand React.js components and API data fetching.

## 4. Features

The Employee Management System includes the following features:

### Employee List

Displays employee information in a structured table.

### Employee Details

The following details are displayed:

- Employee ID
- Name
- Email
- Age
- Department
- Salary
- Location

### Search

Users can search employees by:

- Employee ID
- Name
- Email
- Department
- Location

### Pagination

The application displays 5 employees per page.

Users can navigate through the employee records using:

- Previous
- Page Numbers
- Next

### Responsive Design

The application is designed to work on desktop, tablet, and mobile screen sizes.
